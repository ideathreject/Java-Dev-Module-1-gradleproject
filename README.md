Create a Gradle project. A project must:

1. be packaged in an executable FatJar .jar file with the name myname.jar when the command gradle jar launches
2. print the first and last name in JSON to the console when the command java -jar myname.jar launches. For example, {"name": "Vladyslav", "lastName": "Demchenko"}. For creating JSON string use any third-party library from Maven Central
3. have the correct .gitignore file
4. have the Wrapper (the Wrapper files also need to be uploaded to Github)
